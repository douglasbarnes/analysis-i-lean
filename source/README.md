# Source

The audits are based on two TeX files supplied by the project owner:

- **Analysis I**, Lent 2015, W. T. Gowers;
- **Analysis II**, Michaelmas 2015, N. Wickramasekera.

The original lecture notes are not redistributed in this repository. `THEOREM_AUDIT.md` and
`THEOREM_AUDIT_II.md` record theorem-level line ranges, formalisation status, Mathlib targets, and all
corrections needed before a well-typed Lean statement can be made.
